Gmail 연결 안내

한 번 설치하면 휴대폰에서 앱 주소를 열어 사진을 첨부하고 메일을 보낼 수 있습니다.

현재 로컬 화면은 미리보기입니다. 아래 설치와 Google 권한 승인을 마친 웹앱에서 실제 발송할 수 있습니다.

  1. Google Apps Script에 발송할 계정으로 로그인한 뒤 새 프로젝트를 만드세요. 이름은 출장비 보내기로 정합니다.
  2. 기본 Code.gs의 내용을 모두 지우고 아래 Code.gs 내용을 붙여 넣으세요.
  3. 파일 옆 ＋ → HTML로 Index 파일을 만들고 아래 Index.html 내용을 붙여 넣으세요.
  4. 프로젝트 설정 → 편집기에 appsscript.json 매니페스트 파일 표시를 켜고, 편집기로 돌아와 appsscript.json 내용을 아래 내용으로 교체하세요. 저장합니다.
  5. 배포 → 새 배포 → 유형: 웹 앱을 선택하세요. 실행 사용자: 나, 액세스 권한: 나만으로 설정하고 배포합니다.
  6. Google 권한 화면에서 발송 계정을 확인하고 이메일 발송, 초안 작성, 계정 이메일 주소 확인 권한을 승인하세요. 계정 정책에 따라 관리자 승인이 필요할 수 있습니다.
  7. 생성된 웹 앱 URL을 Android Chrome에서 열어 수신 이메일을 입력하고 주소 저장을 누릅니다. 카메라로 촬영 또는 갤러리에서 선택으로 사진을 올릴 수 있습니다. 발송하지 않고 확인하려면 테스트 초안 저장을 누르고, 실제 발송할 때는 Gmail로 보내기 → 확인하고 보내기를 누르면 됩니다.

Gmail 서비스는 매니페스트에 포함되어 있습니다. 테스트 초안 저장에는 Gmail 초안 작성 권한이 추가로 필요합니다. 별도의 표준 Google Cloud 프로젝트를 연결한 경우 해당 프로젝트에서 Gmail API도 활성화해야 합니다. 개인 기본 프로젝트는 Apps Script 고급 서비스 설정을 사용합니다.

Android Chrome에서 메뉴 → 홈 화면에 추가를 선택하면 앱처럼 바로 열 수 있습니다. Gmail 연동은 웹앱 배포 후 본인 계정으로 권한을 승인해야 활성화됩니다.

사용할 때 알아둘 점

  • JPG/PNG 원본을 최대 30장, 합계 18 MB까지 첨부합니다.
  • 사진은 새로고침하면 지워집니다. Gmail에 저장한 초안과 보낸 첨부는 Gmail에 남습니다.
  • 테스트 초안 저장은 Gmail 임시보관함에만 저장하며 발송하지 않습니다.
  • 발송 결과가 불명확하다고 표시되면 먼저 Gmail 보낸편지함을 확인하세요. 앱은 자동으로 재발송하지 않습니다.
  • 수신자 주소는 Google 계정의 앱 설정에 저장됩니다. 받은편지함 읽기 권한은 요청하지 않습니다.
  • Google의 발송 제한 및 회사 계정 정책이 적용됩니다.
